# Personal AI Coding Playbook

## 1. When I reach for AI first

I use AI when I need help breaking tasks into smaller steps, creating a first draft for a feature, test, or document, or when I am stuck on an error and need ideas to investigate.

## 2. When I do not reach for AI

I don't not use AI when the work includes private or sensitive information.

## 3. My non-negotiables

I am responsible for the changes I make, I do not share passwords, keys, personal data, or private code, and I make sure I understand and test the code before using it.

## 4. My review rules

I read every AI-generated change before accepting it, make sure the code matches the task without adding extra work, and run the relevant tests to fix any problems before submitting.

## 5. What I am still figuring out

I want to learn how to write clearer prompts with useful context, and when I should get a second opinion on AI suggestions.

## 6. Decision Card

- For a new feature I reach for: Copilot in VS Code — that's what I actually used for the last feature I added.
- For a code review I reach for: Copilot and Claude, both given repo access — I have them update/change the code and then run the tests to check it.
- For debugging I reach for: Claude and Codex — that's what got me through the Docker install error I hit.
- For infrastructure I reach for: Codex App.
- I will never paste passwords, keys, or private data into an AI tool.
- My one rule is: I check the work before I use it.
